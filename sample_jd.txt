岗位：AI 应用开发工程师（LLM Agent 方向）
城市：广州  薪资：8-13K

岗位职责：
1. 负责基于大语言模型（LLM）的应用开发，包括智能体（Agent）、RAG 检索增强生成、
   多轮对话系统的设计与落地；
2. 使用 LangChain / LangGraph 等框架搭建多 Agent 协作流程，负责工具调用（Function Calling /
   MCP 协议）的设计与实现；
3. 负责后端服务开发，使用 Python（FastAPI/Django）构建高性能 API 接口，
   配合前端完成前后端联调；
4. 负责提示词工程（Prompt Engineering），持续优化模型输出质量与稳定性；
5. 参与 AIGC 相关能力建设，包括图像生成管线、LoRA 微调、ComfyUI 工作流编排；
6. 负责模型服务的性能优化与成本控制，包括缓存策略、并发调度、token 预算管理。

任职要求：
1. 本科及以上学历，计算机相关专业，1-3 年开发经验（优秀应届生亦可）；
2. 熟练掌握 Python，具备扎实的工程能力，熟悉异步编程（asyncio）；
3. 有 LLM 应用开发经验，熟悉 OpenAI / DeepSeek 等大模型 API 的对接与调优；
4. 熟悉 Docker 容器化部署，了解 CI/CD 流程；
5. 熟悉 MySQL / PostgreSQL / Redis 等常用存储与缓存组件；
6. 有 VLM 多模态、图像生成（Stable Diffusion / Flux）或模型微调经验者优先；
7. 有开源项目或技术博客者优先；
8. 具备良好的沟通能力和团队协作精神，能承受一定工作压力；
9. 有大规模并发服务经验、熟悉 Kubernetes 者优先。

加分项：
- 熟悉 LangGraph、AutoGen、CrewAI 等 Agent 编排框架
- 有 RAG 向量数据库（Milvus / Qdrant / FAISS）实践经验
- 熟悉前端技术（React / Vue）可独立完成全栈开发
